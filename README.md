# مُزن — تطبيق الطقس الأصلي لـ iOS

المصدر الكامل لمشروع SwiftUI موجود في [`iOS/`](iOS/)، بما في ذلك مشروع Xcode والأصول ودليل التشغيل. يعتمد التطبيق على iOS 26+، ويستخدم بيانات الطقس المباشرة من Open-Meteo مع الإسناد داخل التطبيق.

## البناء المستمر وملف IPA

يبني GitHub Actions التطبيق لهواتف iPhone (`generic/platform=iOS`) عند كل دفع إلى `main` أو طلب دمج إليها، كما يمكن تشغيله يدويًا من تبويب Actions. ينتج البناء ملف `Muzn-unsigned.ipa` ويرفعه كـ artifact باسم `Muzn-iOS-unsigned-ipa`.

ملف IPA غير موقّع لعدم توفر شهادة توزيع وملف provisioning في المستودع؛ لذلك **لا يمكن تثبيته مباشرة على iPhone**. يجب توقيعه بتوقيع Apple صالح وتوفير ملف provisioning مناسب قبل التثبيت. لا تُستخدم أسرار توقيع في CI الحالي.

راجع [دليل المشروع](iOS/README.md) للتشغيل والتفاصيل.
