# مُزن — تطبيق الطقس الأصلي لـ iOS

المصدر الكامل لمشروع SwiftUI موجود في [`iOS/`](iOS/)، بما في ذلك مشروع Xcode والأصول ودليل التشغيل. يعتمد التطبيق على iOS 26+، ويستخدم بيانات الطقس المباشرة من Open-Meteo مع الإسناد داخل التطبيق.

## البناء المستمر

يبني GitHub Actions التطبيق لمحاكي iOS عند كل دفع إلى `main` أو طلب دمج إليها، كما يمكن تشغيله يدويًا من تبويب Actions. لا يتطلب البناء توقيعًا أو ملفات أسرار.

راجع [دليل المشروع](iOS/README.md) للتشغيل والتفاصيل.
